## O fluxo em uma linha

Ideia (Niche Finder) → roteiro → voz (a nossa, clonada ou DarkPlanner) → imagens e vídeos de IA (ComfyUI / Flow) → motion (Remotion) → montagem (EffectCraft) → render final (FilmCraft) → thumbnail e postagem (YouTube, TikTok e Instagram pelo navegador, via CDP).
